# TalentForge Resume Formatter

## Overview

TalentForge is a sleek resume processing application that transforms raw resumes into professionally formatted documents. Users can upload single or multiple resumes, watch captivating processing animations, and download polished results.

## Target Users

- **Recruiters** processing multiple candidate resumes
- **Job seekers** wanting professionally formatted resumes
- **HR professionals** standardizing resume formats across applications

## Key Features

- **Single & Batch Upload**: Drag-and-drop or click to upload one or many resumes
- **Real-time Processing Status**: Live updates with mesmerizing loading animations
- **Instant Downloads**: One-click download of formatted resumes
- **Visual Feedback**: Every state transition has purposeful, delightful animation

## Design Direction

**Aesthetic**: Futuristic corporate minimalism with electric accent colors. Dark theme with subtle gradients, geometric patterns, and smooth micro-interactions. Typography uses a bold display font paired with clean sans-serif body text.

**Color Palette**: Deep navy/charcoal backgrounds, electric cyan/teal accents, soft white text.

**Motion**: Orchestrated page load reveals, smooth drag-drop feedback, pulsing/morphing processing indicators, satisfying completion animations.

## Technical Integration

- TalentForge Resume Processing API (Azure-hosted Python backend)
- Endpoints: Upload, Batch Upload, Process, Status Check, Download
